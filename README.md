### Projetos

**WorkoutHeavy** · aplicação web de treinos, feita do banco de dados à interface

- [WorkoutHeavyAPI](https://github.com/AlguemChamadoEverton/WorkoutHeavyAPI): API REST em C# com ASP.NET Core (Minimal APIs), autenticação JWT, PostgreSQL com Entity Framework Core e documentação com Swagger UI.
- [WorkoutHeavyFront](https://github.com/AlguemChamadoEverton/WorkoutHeavyFront): front-end em JavaScript, HTML e CSS, sem frameworks, consumindo a própria API. Tem cadastro, login por token, montagem de rotinas, comentários, curtidas e busca de usuários.

**[servidor-http-em-c](https://github.com/AlguemChamadoEverton/servidor-http-em-c)** · sistema de cadastro em C, escrito do zero

- Lista encadeada em memória com persistência em CSV. Funciona como menu de terminal, servidor TCP com protocolo próprio e servidor HTTP que responde direto no navegador.

**[AutoEscolaS042](https://github.com/AlguemChamadoEverton/AutoEscolaS042)** · API REST em Java com Spring Boot

- Desenvolvida durante o curso de API REST com Spring Boot do Senai São Paulo. Tem cadastro de alunos e instrutores, agendamento de instruções e autenticação de usuários.
